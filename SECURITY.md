# Security Policy

## Important Notices

> [!WARNING]
> If you are still using versions v3, v5 or v6 please migrate to v7.

> [!CAUTION]
> Versions v1, v2, v3, v4 and v5 are no longer supported.

## Support Key

> [!NOTE]
> :white_check_mark: : Actively Supported
>
> :construction: : Under Development
>
> :x: : Not Supported
>
> `-` : Wasn't ever supported

below to notify us of any vulnerabilities.
